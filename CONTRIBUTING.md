# Contributing

Thanks for your interest in contributing to `superagent`.

This is a small test repository for
[dsh-superagent](https://github.com/deepseek-ai/dsh-superagent-prototype).

## Running tests

There is currently no automated test suite in this repository, so there are no
test commands to run.

When tests are added, the command to run them will be listed here (for example
`npm test`), together with any setup steps such as installing dependencies.

## Opening a pull request

1. Fork the repository and clone your fork.
2. Create a branch for your change:

   ```sh
   git checkout -b my-change
   ```

3. Make your changes and commit them with a clear message.
4. Push your branch:

   ```sh
   git push origin my-change
   ```

5. Open a pull request against the `main` branch of `tom666lee/superagent`.
6. Describe what your change does and why.

Maintainers will review your pull request. Thank you for contributing!
